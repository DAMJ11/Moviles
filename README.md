## 🚀 Cómo Ejecutar el Proyecto

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar el servidor de desarrollo
npx expo start
```

- Presiona `w` para probar en el navegador web.
- O escanea el código QR con la app móvil **Expo Go** en tu celular.
